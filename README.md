# 电控第一次作业 · STM32F103 LED 控制

基于 **STM32F10x 标准外设库** 的 Keil MDK 工程。

用三个按键切换 LED 的三种工作模式，练习了 GPIO 输出、软件延时与定时器延时、定时器 PWM 输出、外部中断与按键消抖。

---

## 功能说明

LED 接在 **PB0**，共三种模式，用 PA0 / PA1 循环切换：

| 模式 | `LED_Mode_Flag` | 现象 | 实现方式 |
| :--: | :--: | --- | --- |
| 0 | 0 | 每 250 ms 翻转一次电平 | GPIO 推挽输出 + TIM2 精确定时延时 |
| 1 | 1 | 1 Hz 方波（亮 0.5 s / 灭 0.5 s） | TIM3_CH3 硬件 PWM，占空比 50 % |
| 2 | 2 | 保持当前电平，可用 PA2 手动翻转 | GPIO 输出 + EXTI2 外部中断 |

按键操作：

- **PA0**：模式 +1（0 → 1 → 2 → 0 循环）
- **PA1**：模式 −1（2 → 1 → 0 → 2 循环）
- **PA2**：翻转 LED 电平（仅在模式 2 下有效）

---

## 硬件连接

| 引脚 | 配置 | 用途 |
| --- | --- | --- |
| `PB0` | 推挽输出 / 复用推挽 | LED，同时也是 `TIM3_CH3` 的 PWM 输出脚 |
| `PA0` | 下拉输入 IPD | 按键：模式 +1，EXTI0 上升沿触发 |
| `PA1` | 下拉输入 IPD | 按键：模式 −1，EXTI1 上升沿触发 |
| `PA2` | 下拉输入 IPD | 按键：翻转电平，EXTI2 上升沿触发 |

三个按键均为**下拉输入 + 上升沿触发**，因此按键另一端接 **3.3 V**。

---

## 定时器资源分配

系统时钟按 72 MHz 计算：

| 定时器 | 预分频 / 周期 | 实际频率 | 用途 |
| :--: | --- | :--: | --- |
| `TIM2` | 72 − 1 / 1000 − 1 | 1 kHz | 1 ms 时基，供 `Delay_ms_Mode2()` 做精确延时 |
| `TIM1` | 72 − 1 / 20000 − 1 | 50 Hz | 20 ms 按键消抖，单次触发后自动关闭 |
| `TIM3` | 7200 − 1 / 10000 − 1 | 1 Hz | CH3 输出 PWM 方波，`TIM_Pulse = 5000`（占空比 50 %） |

---

## 按键消抖思路

没有用 `while` 死等松手，而是「中断触发 + 定时器二次确认」：

1. 按键按下 → 触发 `EXTI0` / `EXTI1` / `EXTI2` 上升沿中断；
2. 中断里只记录是哪个键被按下（写入 `LED_Debounce_Flag`），随后启动 `TIM1`；
3. 20 ms 后 `TIM1` 更新中断到来，此时再读一次引脚电平做确认；
4. 确认有效才真正修改 `LED_Mode_Flag`，并关闭 `TIM1` 等待下一次触发。

这样消抖期间 CPU 不被占用，主循环可以照常运行。

## 编译与烧录

1. 安装 **Keil MDK-ARM**，并装好 STM32F1 系列的 Device Family Pack；
2. 双击 `project.uvprojx` 打开工程；
3. `F7` 编译，产物（`.hex` / `.axf`）输出到 `Objects/`；
4. 接好仿真器后 `F8` 下载。

> `Objects/`、`Listings/` 等编译产物已在 `.gitignore` 中排除，clone 下来直接编译即可重新生成。

## 开发过程中的几种方案对比

工程里以注释形式保留了被替换掉的实现，便于对比：

| 函数 | 位置 | 思路 | 为什么换掉 |
| --- | --- | --- | --- |
| `LED_Flash_Mode1()` | `led.c` | 纯循环计数延时（`Delay_ms_Mode1`） | 延时靠空转，不精确且占满 CPU |
| `LED_Flash_Mode2()` | `led.c` | 用 TIM2 的更新标志做 1 ms 延时 | 当前模式 0 采用的方案，精度 1 ms |
| `LED_Flash_TIM1()` | `led.c` | TIM2 中断计满 500 次再翻转 | 依赖主循环轮询标志，实时性差 |
| `LED_Flash_TIM2()` | `led.c` | TIM3_CH3 硬件 PWM 直接输出方波 | 当前模式 1 采用的方案，不占 CPU |
| `Button_Mode_Change()` | `button.c` | 轮询 + `while` 等松手 | 会阻塞主循环，改为中断 + 定时器消抖 |

---

## 说明

- 模式 0 的 `LED_Flash_Mode2()` 内部是死循环，主循环不会返回；模式切换依赖 EXTI 中断完成，属于预期行为。
- 模式 2 下 LED 保持当前电平不动，按 PA2 才翻转。
